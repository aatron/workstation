# VS Code / Cursor settings

Copies of user settings and keybindings to sync into your editor User directory (not live config).

- `usersettings.json` — paste or merge into Cursor/VS Code `settings.json`
- `keybindings.json` — paste or merge into Cursor/VS Code `keybindings.json`
